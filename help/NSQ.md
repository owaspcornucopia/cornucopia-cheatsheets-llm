# NSQ — Unencrypted network channel

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

NSQ describes reading or modifying sensitive data sent over an unencrypted communication channel.
The clients use bundled or locally prepared model artifacts, local SQLite, and does only do local AI inference.
No sensitive investigation data is sent across a runtime network channel.
