# PCK — Native memory corruption

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

PCK describes memory leaks or corruption caused by unsafe resource management or missing native compiler protections.
The apps include native model/runtime code, but the scenarios do not contain a deliberate, reproducible buffer overflow, use-after-free, or native memory-corruption bug.
