# CM4 — Missing downstream data-sharing consent

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM4 requires the app to share personal data with downstream services without clearly disclosing the sharing or obtaining consent.
The model, database, and fraud decision flow run locally and no downstream data service can receive user
data as none is collected.
