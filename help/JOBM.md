# JOBM — Covert surveillance

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

JOBM requires using the installed app to surveil, eavesdrop on, remotely control, track, or monitor another person without consent or notification.
The clients use sensitive transactions in a visible investigation flow, but they do not implement covert sensors, tracking, remote control, or surveillance collection.
