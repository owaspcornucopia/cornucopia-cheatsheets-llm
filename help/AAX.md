# AAX — Missing remote or cryptographic authentication

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

AAX concerns authentication that should be enforced by a remote endpoint or by a cryptographic primitive protected with keystore or keychain access control.
The scenarios have no user login, remote authentication endpoint, or keystore-bound authentication protocol. Their deliberately weak client-side authorization inputs are covered by the selected authorization cards.
