# AA3 — Misconfigured biometric authentication

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

AA3 requires a biometric authentication flow, an insecure fallback, or a biometric configuration change that affects access to a sensitive feature.
Neither client presents a biometric prompt or uses biometric state to authorize an investigation or report action.
