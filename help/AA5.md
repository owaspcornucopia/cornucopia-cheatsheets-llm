# AA5 — Credential interception through misdirection

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

AA5 requires a credential-bearing login or authentication flow vulnerable to Tapjacking, task hijacking, or URL-scheme credential interception.
The apps have no user credential screen or login token exchange.
Their custom or exported integration inputs carry investigation data and test authorization flags, but no user credentials.
