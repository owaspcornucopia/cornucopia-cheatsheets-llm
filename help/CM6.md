# CM6 — Repurposed biometric data

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM6 requires biometric information collected for security to be repurposed for commercial or unrelated use.
Neither client collects, stores, or processes
biometric data, and neither has a biometric authentication workflow.
