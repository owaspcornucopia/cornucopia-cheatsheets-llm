# CM3 — Missing user data controls

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM3 requires user-facing controls to manage, delete, or change privacy settings for collected personal data. The training apps have no user account, privacy settings, consent re-prompt, or data-management workflow. The
transaction data may be sensitive, but it's not related to the app user's privacy.
