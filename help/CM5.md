# CM5 — Repurposed personal data

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM5 concerns repurposing personal data collected for fraud prevention or security for an unrelated commercial purpose without informed consent.
The scenario contains sensitive transactions, but no commercial data-use or secondary data collection.
