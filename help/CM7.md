# CM7 — Notification phishing

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM7 requires notification content or notification actions that can be manipulated to launch a phishing campaign. The clients do not send notifications or expose notification action destinations.
Declared notification permission text is a separate permission issue.
