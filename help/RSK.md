# RSK — Bypassed anti-reversing controls

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

RSK requires anti-reversing or runtime-protection checks that an attacker can disable or evade.
These builds do not implement such checks.
Readable code, debug metadata, and runtime instrumentation are conditions covered by other selected resilience cards.
