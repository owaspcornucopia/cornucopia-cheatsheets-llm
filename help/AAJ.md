# AAJ — Incomplete centralized authentication

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

AAJ assumes that a centralized authentication and authorization control exists, but is not applied comprehensively.
These training clients have no centralized authentication service or framework; they run the investigation locally and use deliberately scoped client-side authorization behaviors.
