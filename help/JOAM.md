# JOAM — Mandate non-compliance

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

JOAM is a Wild Card about using or altering the app so it no longer complies with legal, regulatory, contractual, or other mandates.
The scenarios do not implement a compliance decision, regulatory control, or contractual obligation that can be attacked as a distinct application behavior.
