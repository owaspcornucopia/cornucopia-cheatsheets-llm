# CM9 — Unauthenticated external protected data

## Non-Applicable

This threat is not selected for the current Android or iOS scenarios.

## Reasoning

CM9 requires protected data received from an external service that the app fails to authenticate or verify.
The transaction database and result from the model are created and consumed on the local device
There are no external services that is triggered through the fraud investigation.
